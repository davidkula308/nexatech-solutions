11. You can also sell software licenses

There are two different things you should clearly separate:

Software installation

Customer already has a legitimate license/account.

You charge for your installation service.

Software license

You sell or facilitate a legitimate subscription/license.

Customer pays for the software license + your service fee.

This distinction is important because some software—particularly Autodesk products—has specific licensing terms. Autodesk's education licenses, for example, are intended for educational purposes and aren't permitted for commercial/professional for-profit use.

So your website should say something like:

We provide software installation and licensing assistance using legitimate software and authorized licensing options.
